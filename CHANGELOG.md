# Changelog

## [0.1.2] - 2026-11-16

- Introduce `omt-obsidian` preset: modern developer cockpit with Left-Rail Spine (`▎`), Solid Inverted Chips (` ▊ READ `), Foldable Reasoning Capsule (`◈ Reasoned in X.Xs ▸`), and 8-slot Context Fuel Gauge (`▰▰▰▱▱▱▱▱`).
- Preserve `omt-signature` 100% to its original Pitago layout, bullets, and grouping behavior.
- Add bounded tool output clamping (8 lines for shell, 12 lines for read, 24 lines for diffs) to prevent terminal scrollback flooding.
- Step-by-step uncollapsed tool progress tracking in `omt-obsidian`.
- Add autocompletion support for `omt-obsidian` and `obsidian` in `/omt theme` and `/omt preset`.

## [0.1.1] - 2026-11-15

- Fix showcase image and GIF URLs in README for npm and Pi Marketplace gallery.
- Add `pi.image` gallery preview thumbnail.

## [0.1.0] - 2026-11-10

- Five presentation presets: OMT Clean, OMT Ember, OMT Rail, Minimal and Native.
- Renamed preset IDs and their saved per-preset scenes/assets migrate automatically; no manual `omt.json` edits are needed.
- Composer, message, tool, statusline and progress styling.
- Settings, command palette, conversation navigation and tool inspection.
- Git changes, session browsing, conversation export and branch navigation.
- Draft management, prompt queue views, notifications and diagnostics.
- Accessibility options, focus layouts and transcript browsing.
- Procedural scenes and imported image/animation backgrounds.
